# Privacy Information

This page describes the current documentation status for Eiyū no Michi. It is not a claim that the application has completed an independent privacy audit.

## Data handling status

The data collected, stored, or transmitted by every application component has not yet been fully verified for this public project page.

Before publishing an APK, the project should document and verify:

- Whether the application connects to any network services
- Whether diagnostics, analytics, or crash reports are collected
- What information is stored locally
- Where save data and configuration files are stored
- Whether any third-party SDKs or services process information

## User guidance

Do not send passwords, signing keys, private save files, or other sensitive information in public issue reports.

For privacy questions, open an issue in this repository without including personal or sensitive data.
