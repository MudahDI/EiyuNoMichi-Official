# Security Policy

## Reporting a security issue

Please do not publish exploitable security details, private files, signing credentials, or personal information in a public issue.

For a non-sensitive report, open a GitHub issue and provide:
- The affected application version
- Android version and device model, if relevant
- A clear description of the problem
- Steps to reproduce that do not expose private data

## Release security status

A public release package is not provided by this repository at this time. Before any APK distribution, the release process should verify the package signature, dependencies, permissions, bundled files, and build provenance.

Never share keystores, signing passwords, GitHub secrets, BIOS files, or copyrighted game images in issues or pull requests.
